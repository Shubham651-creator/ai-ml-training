# Statistics Fundamentals

1. Mean 
    - Average of dataset

2. Mode
    - Maximum number repetited (frequency)

3. Median
    - Average of center of two number after sorting the dataset
    - Median prevents distortion of data due to outliers.

4. Variance
    - How far data spread from the MEAN

5. Standard Deviation
    - Squre root of Variance
    - Average distance from Mean
    - Outlier detection

# Probability & Normal Distribution

1. Probability = Chances of happening something
    - How likely is this prediction correct?

2. Random Variables
    - Event & values
    - e.g dice roll has values {1,2,3,4,5,6}

3. Normal Distribution
    - Distribution = How data is spread
    - Data Pattern
    - Bell shaped curve
    - Mean= Mode= Medium i.e Symmetrical
    - Almost all data lies near mean
