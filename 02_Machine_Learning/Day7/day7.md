# Supervised Learning
## Generelization
- Model perform well on Unseen data

### Good ML Models are Learns Patterns, Not Memorization

## Overfitting Vs. Underfitting
### Overfit
- Model memorize training data instead of learning real patterns.
- Train Accurancy: very high
- Test Accurancy: Low
- High BIAS

### Why Overfitting Happens
- too many features
- too little data
- very complex model
- noise in data

### Underfit
- Model is too simple to learn patterns.
- Train and Test Accurancy: Low
- High VARIANCE (Higher impurity)

## Perfect Balance
- Learn actual pattern without memorization.

## Decision Tree Regressor Algorithm
- max_depth = 1  - underfit
- max_depth = 3  - depends
- max_depth = 20 - overfit
