# Employee Turnover Analysis

- A company is facing high employee attrition ( leaving company).

- This causes:
    - hiring cost
    - training cost
    - project delays
    - productivity loss

- The HR department want a AI/ML system that can predicts:
    > Which employee are likely to leave the company before they resign?

---
## Input Dataset 
IBM HR Analytics Employee Attrition & Performance

### Target variable
- Attrition (Leave/stay)
---

### Execution flow
1. employee_attrition.csv
2. EDA.ipynb
3. preprocessing.py
4. train.py
5. evaluate.py
6. predict.py
7. Business Insights

---

## By end of project you should answer
1. Which department has highest attrition?
2. Does overtime increase attrition?
3. Does low salary increase attrition?
4. Does job satisfaction affect retention?
5. Which feature is most important?
6. Can we predict employees likely to leave?
